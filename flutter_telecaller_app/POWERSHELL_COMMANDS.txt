========================================
PowerShell Commands - Copy Paste Karein
========================================

Step 1: Flutter PATH Set Karein
--------------------------------
$env:PATH += ";C:\flutter\bin"

Step 2: ANDROID_HOME Set Karein
--------------------------------
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"

Step 3: Licenses Accept Karein
-------------------------------
flutter doctor --android-licenses

Phir har prompt par 'y' type karein aur Enter press karein.
