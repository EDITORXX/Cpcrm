✅ METHOD 2: Step by Step
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Flutter Install करें
   → AUTO_SETUP.bat run करें
   या manually:
   → https://flutter.dev/docs/get-started/install/windows से download करें
   → C:\flutter में extract करें
   → PATH में C:\flutter\bin add करें

STEP 2: APK Build करें
   → INSTALL_AND_BUILD.bat run करें
   या manually:
   → Command Prompt में:
     cd flutter_telecaller_app
     flutter pub get
     flutter build apk --release

STEP 3: Server Start करें
   → START_SERVER.bat run करें
   या manually:
   → php artisan serve --host=0.0.0.0 --port=8000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
